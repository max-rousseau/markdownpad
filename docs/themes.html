markdownpad / themes

The quiet room

A focused, Notepad-inspired markdown editor for macOS. Open, edit, save markdown files. Open .md files, toggle between edit and view modes with ⇧⌘P, and let links and code render inline. That's it.

Features

  • GitHub-flavored markdown rendering
  • Syntax-highlighted code blocks
  • Inline mermaid diagrams
  • Interactive task-list checkboxes

Most of writing is just sitting down and doing it. The tools should get out of the way.

Sample code

// Returns the resolved theme based on the user's preference.
export function resolveTheme(pref: Theme): ResolvedTheme {
  if (pref === 'system') {
    return matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark'
      : 'light';
  }
  return pref;
}
